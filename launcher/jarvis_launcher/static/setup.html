J.A.R.V.I.S.

Starting up…

JARVIS is a dashboard and voice for Hermes Agent, Nous Research's open-source AI agent. Hermes is the brain: it does the thinking, remembers, and runs your tools. JARVIS doesn't include it, so it needs a Hermes to talk to.

Found earlier JARVIS data in this volume (settings, memories, logins). Installing Hermes keeps all of it.

Here is exactly what happens when you continue:

  1. JARVIS downloads Nous Research's official installer from and runs it inside this container.
  2. It installs Hermes Agent (source, MIT license) from the release channel into , with its own Python, Node and tools. That's about 1.5 GB, and takes a few minutes.
  3. Hermes keeps its settings, memories and chats in , the same volume as JARVIS, so updating or replacing the JARVIS container keeps everything.
  4. JARVIS then sets Hermes up for itself: it turns on Hermes's API server (only reachable inside this container), installs the JARVIS connector plugin, and points Hermes's browser at the browser desktop.
